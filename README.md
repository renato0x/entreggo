# Entreggo

## O que é

A Entreggo é uma plataforma local de despacho de entregas. Pequenos comércios publicam uma demanda de entrega e entregadores afiliados disponíveis podem aceitá-la e executá-la.

O primeiro recorte são comércios de preparo rápido — hamburguerias, pastelarias, sorveterias e similares — em uma área geográfica pequena e validada.

## Estado do projeto

Estamos na fase de descoberta e definição do produto. Não há produto em desenvolvimento nesta etapa; este repositório guarda apenas a documentação que precisa estar consolidada antes da implementação.

## Problema

Pequenos comércios dependem de WhatsApp, contatos informais ou serviços caros para encontrar um entregador no momento do pedido. Isso gera demora, baixa previsibilidade e pouca visibilidade operacional.

## Proposta

Dar ao comércio uma forma rápida de criar uma corrida e aos entregadores afiliados uma fonte previsível de demandas locais, com o status da entrega visível para as partes envolvidas.

## Fluxo inicial

```text
Comércio cria a entrega
        ↓
Entregadores elegíveis recebem a oferta
        ↓
Um entregador aceita
        ↓
Coleta → entrega → confirmação
        ↓
Comércio recebe o resultado da corrida
```
