# Registro de decisões

Use este documento para evitar que hipóteses virem requisitos implícitos.

| Tema | Decisão atual | Estado | Próxima evidência necessária |
| --- | --- | --- | --- |
| Público inicial | Comércios locais de preparo rápido e entregadores afiliados | Definido | Escolher cidade e bairros do piloto |
| Modelo do produto | Plataforma de despacho; não é marketplace de cardápios | Definido | Validar valor para os dois lados |
| Território | Ainda não escolhido | Aberto | Mapear concentração de comércios e entregadores |
| Cobrança | Ainda não escolhida | Aberto | Testar aceitação de comissão ou preço por corrida |
| Distribuição de ofertas | Oferta simultânea para elegíveis no piloto | Hipótese | Medir taxa e tempo de aceite |
| Confirmação de entrega | Código ou confirmação do comércio | Hipótese | Testar incidência de conflitos |
| Cadastro de afiliados | Aprovação manual inicial | Definido | Definir documentos e critérios mínimos |
| Pagamentos | Fora do MVP | Definido | Definir processo manual no piloto |
| Produto do consumidor | Fora do MVP | Definido | Reavaliar apenas após validar despacho |

## Como registrar uma nova decisão

Para cada decisão, registre a hipótese, quem decidiu, data, evidência usada e a condição que faria a decisão ser revista.
